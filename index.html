About

My background is in embedded systems and applied AI. My senior project, GestureTalk, is a real-time Thai hand-sign recognizer that tracks hand landmarks with MediaPipe and classifies them with a neural network running entirely in the browser — no server involved. Projects like that taught me how to move data reliably from a sensor, through processing logic, to something a person can actually use. That same instinct — build the pipeline, handle the state, make the interface make sense — is what I'm now applying to web development.
